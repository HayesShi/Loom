# Datasets

The [Datasets release](https://github.com/HayesShi/Loom/releases/tag/datasets-v1)
contains input graphs, targets, and fixed data partitions. The repository stores
the file inventory and download script; large arrays are release assets.

```bash
python scripts/download_data.py --list
python scripts/download_data.py --only node-benchmarks paris
python scripts/download_data.py
```

The full download is approximately 3.49 GiB. Files are restored under `data/`,
except 2Dele, which retains its upstream directory structure. The downloader
joins the six Plate archive parts automatically. `--from-local PATH` restores
previously downloaded assets; `--root PATH` selects the destination directory.

| Package | Datasets | Content |
|---|---|---|
| `node-benchmarks` | Cora, CiteSeer, PubMed, DBLP, WikiCS, ogbn-arxiv, Coauthor-CS, Coauthor-Physics, Roman Empire, Amazon Ratings, Chameleon-filtered, Minesweeper, Tolokers, Questions | Graphs and masks; original Planetoid files |
| `graphland` | Roads-M, Tolokers-2, Artnet-exp, Artnet-views, City-reviews, Twitch-views, Roads-L | Features, targets, edges, and supplied splits |
| `paris` | City-Networks Paris | Original features, topology, labels, and masks |
| `lrim` | Four LRIM variants | Original graph lists |
| `echo-sssp` | Six ECHO-SSSP topology families | Original train, validation, and test partitions |
| `2dele` | 2Dele | Original data partitions |
| `hodge` | Hodge magnetostatics | Samples generated by the upstream solver and saved split |
| `laplace` | Laplace2d | Training, validation, transfer domains, and reference meshes |
| `plate-prepared` | Plate | Prepared static graphs and preparation metadata |
| `plate-original` | Plate | Original trajectory archive |

Node NPZ files contain `node_features`, `node_labels`, `edges`, and
`train_masks`, `val_masks`, `test_masks`. The example uses the public Planetoid
split for Cora, CiteSeer, and PubMed. Other node graphs retain their saved masks
and are standardized using training-node statistics.

PyTorch graph files require the `data` dependencies. The legacy 2Dele objects
also require their upstream Python classes. Clone the source before restoring
that dataset:

```bash
git clone https://github.com/Supradax/Higher-Order-Differential-Topology-aware-GNN external/Higher-Order-Differential-Topology-aware-GNN
python scripts/download_data.py --only 2dele
```
